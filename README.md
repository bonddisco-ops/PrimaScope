<h1 align="center">P R I M A S C O P E</h1>

Осциллограф для мастер-шины (VST3 / CLAP, Windows · macOS · Linux) с сайдчейном, записью волны,
визуальной симуляцией компрессора, линейкой и порогами громкости.

## Установка
1. Откройте вкладку **Actions** → последний успешный запуск → внизу раздел **Artifacts**.
2. Скачайте архив для своей системы и распакуйте.
3. Скопируйте плагин:
   - **Windows:** `PrimaScope.vst3` → `C:\Program Files\Common Files\VST3\`, `PrimaScope.clap` → `C:\Program Files\Common Files\CLAP\`
   - **macOS:** `PrimaScope.vst3` → `~/Library/Audio/Plug-Ins/VST3/`, `PrimaScope.clap` → `~/Library/Audio/Plug-Ins/CLAP/`
     (плагин не подписан — если macOS блокирует: `xattr -cr ~/Library/Audio/Plug-Ins/VST3/PrimaScope.vst3`)
   - **Linux:** `~/.vst3/` и `~/.clap/`
4. Пересканируйте плагины в DAW.

## Возможности и управление

| Что | Как |
|---|---|
| **Режимы каналов** | `L / R`, `M / S` (две дорожки одновременно), `L`, `R`, `M`, `S` — кнопки в шапке |
| **Сайдчейн** | Подайте сигнал на вход Sidechain плагина в DAW. Кнопка `SC` показывает/скрывает его — **бирюзовым** поверх основного **розового** сигнала |
| **Запись** | `● REC`. Режим `BARS` — запись стартует с ближайшего такта, длина 1/4…8 тактов (темп берётся из DAW). Режим `SEC` — 1…30 с. Максимум 30 с. Записанная волна остаётся на экране |
| **LIVE / CAPTURE** | Переключение между живым сигналом и записанной волной |
| **Зум / прокрутка** | Колесо — масштаб по времени (к курсору), Shift/Ctrl + колесо — по амплитуде, перетаскивание — прокрутка записи, двойной клик — показать всю запись |
| **Линейка** | `RULER`, затем тяните по волне: Δ в **мс**, частота 1/Δt, длина в долях (`= 1/8`), разница уровней в dB. Правый клик — убрать |
| **Пороги громкости** | `LINE +`, затем клик по волне. Линию можно двигать мышью, правый клик по линии — удалить, `CLEAR` — удалить все. Пороги **не исчезают** при переключении треков и сохраняются в проекте |
| **Наведение** | Время, позиция в такте, уровень в dB, **частота** (FFT вокруг курсора) + нота, сжатый уровень и GR, уровень сайдчейна |
| **Симуляция компрессора** | `SHOW ADVANCED` → `PREVIEW ON`. Threshold, Ratio, Attack, Release, Knee, Makeup. Белая волна — результат после компрессора, янтарная кривая — gain reduction, пунктир — порог. `KEY: SIDECHAIN` — компрессор управляется сайдчейном. **Звук не меняется** — только показ. Лучше всего работает на записанной волне: крутите ручки и сразу видите результат |

Ручки: перетаскивание вверх/вниз, Shift — точная настройка, двойной клик — сброс.

## Частота при наведении
Для одиночных звуков (бочка, бас, саб) показывается точная основная частота. В плотном миксе —
доминирующая частота спектра вокруг курсора (~170 мс окно), это оценка, а не единственный ответ.

## Сборка вручную
```
cargo xtask bundle primascope --release
```
Плагины появятся в `target/bundled/`.
